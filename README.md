# Vanshika Singh — Research Portfolio

A responsive static research portfolio with a green-led editorial design, interactive homepage research lenses, an image-led writing collection, searchable category tabs, a summary/full-text reader, and expandable coursework details.

## View the site

**Fastest preview:** open `vanshika_research_portfolio_preview.html` in a browser. This standalone file embeds the website code and the local research assets. It still uses credited remote URLs for contextual image tiles, so those images require an internet connection.

**Full project:** unzip `vanshika_research_portfolio.zip` and open `index.html` in Chrome, Edge, Firefox or Safari. The separate files in the project folder make the site easier to edit and publish.

## What is included

- **14 writing and research entries** in one unified Writing section, presented as image-led tiles.
- Functional topic/category tabs and search.
- Prominent **Summary** and **Read full text** controls; items with supplied source PDFs open the original page sequence in an embedded PDF viewer.
- Six original maps extracted from the supplied Ola Mobility Institute walkability PDF. The card and full document are linked to the actual paper.
- Figures extracted from the supplied green hydrogen policy-review DOCX, plus PDF renderings of the green hydrogen review and Rajasthan education-technology memo so their figures, paragraph flow, tables and captions remain in document order.
- Contextual image tiles from relevant web sources where a writing sample did not contain a suitable original visual. See `assets/IMAGE_CREDITS.md`; these are explicitly distinguished from original research outputs.
- Ten named M.A. Public Policy course titles, documented methods/skills, and coursework output index.
- Full transcribed text and original DOCX for the forest-cover paper.
- Full text of the Chiranjeevi health-insurance report transcribed from the author-provided paste, with the summary focused on the distinction between enrolment, use and genuine financial protection. Three image placeholders are retained where the pasted source referred to figures that were not supplied.

## Files

- `index.html` — site structure and homepage.
- `styles.css` — layout, palette, tile cards, interactions and responsive styling.
- `app.js` — category filters, search, writing reader, PDF views, course accordions, theme selectors and navigation.
- `data.js` — structured content for all work entries, themes, skills and courses.
- `assets/` — original research documents, PDF reading versions, extracted maps/figures and image attribution notes.

## Visual and content integrity

Original maps and figures are used where they are available in the uploaded source files. The Rajasthan education-technology memo now includes its full source document and an adjacent-page-faithful PDF reading view. Contextual photographs or reference maps are credited and are not represented as original analysis. Source PDFs preserve the original map/figure position in the paper; where only a summary is available, the site does not fabricate the missing full text.

Before public launch, confirm publication permissions for work produced during internships and government placements (including the Rajasthan education-technology memo), review claims in the forest-cover paper for factual currency, and add an approved public CV/contact details if desired.

## Publish or edit

This is a static site and requires no API key or build step. You can host the contents of the project folder on a static hosting provider. Do not publish internal work or original files unless you have permission to share them.
